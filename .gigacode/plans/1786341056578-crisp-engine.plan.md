# План реализации системы аутентификации с PostgreSQL

## Текущее состояние проекта
- **Фронтенд**: Vanilla JS SPA, localStorage, hash-based роутинг
- **Бэкенд**: Express 5, статическая раздача файлов, SSE, экспорт Excel
- **Аутентификация**: отсутствует
- **База данных**: отсутствует

## Цель
Добавить server-side аутентификацию, управление пользователями и статистику

## Архитектура
- PostgreSQL как хранилище пользователей и статистики
- Express sessions для аутентификации
- Рели: admin (полный доступ), operator (создание турниров)

## Этапы реализации

### Этап 1: PostgreSQL и бэкенд
1. Установить pg (PostgreSQL driver)
2. Создать базу данных и таблицы:
   - users (id, username, password_hash, role, display_name, created_at)
   - login_logs (id, user_id, login_time, ip, user_agent)
   - user_activity (id, user_id, action, target_type, target_id, created_at)
3. Реализовать API:
   - POST /api/auth/login
   - POST /api/auth/logout
   - GET /api/auth/me
   - CRUD /api/admin/users
   - GET /api/stats/*

### Этап 2: Фронтенд
1. Экран логина (renderLogin())
2. Проверка сессии при загрузке
3. Админ-панель для управления пользователями
4. Статистика

### Этап 3: Интеграция
1. Защита существующих API (publish, save)
2. Логирование действий
3. Тестирование
